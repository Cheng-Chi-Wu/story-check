# Story Check frontend

Next.js 16, React 19, Tailwind 4 and three.js (react-three-fiber). See the [project README](../README.md) for what the app does and how to run the backend.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build
npx tsc --noEmit -p . && npx eslint .
```

Set `NEXT_PUBLIC_API_URL` to the backend address; it defaults to `http://localhost:8000`.

| Path | What it holds |
| :--- | :--- |
| `app/page.tsx` | The single page: state, sample loading, run and export |
| `components/SetupPanel.tsx` | File upload, paste box, project settings |
| `components/BuildingViewer.tsx` | 3D story model |
| `components/StoryPanel.tsx` | Summary numbers, notices, story list and check details |
| `lib/api.ts`, `lib/types.ts` | API client and the result types |
| `public/samples/` | Sample buildings and their precomputed results, generated by `python -m backend.mock_data_gen` |
